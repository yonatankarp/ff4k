> [!WARNING]
> **Breaking release.** 0.4.0 redesigns the API around a much smaller surface. Every public type, the JSON configuration format and the store schemas change, with no deprecation period.

## Highlights

- **Small, idiomatic API.** `Feature` and `Property<T>` are plain data classes, `FeatureStore` and `PropertyStore` have four or five suspend functions, and `FlippingStrategy` is a `fun interface` composable with `and`, `or` and `!`.
- **Pluggable everywhere.** Custom strategies and custom property value types register through the kotlinx serializers module, and any store can be verified with `ff4k-contract-test`.
- **Backend databases.** `ff4k-store-jdbc` now covers PostgreSQL and MySQL on any `DataSource`, and `cached()` keeps flag checks off the database.
- **Permissions are enforced.** A feature with `permissions` is active only for callers passing a matching role under `FF4k.ROLES`.

Published for the JVM only, built with Kotlin 2.4.
